# car-customization
Atelier 9 Tuning Garage
About the Project
Atelier 9 Tuning Garage is an interactive car customization project designed to provide a virtual garage experience.
The project allows users to explore a car customization interface and interact with available visual features.
It was developed as a personal web development project.
How to Run
1. Download or clone this repository.
2. Open the Atelier 9 Tuning Garage folder.
3. Find the index.html file.
4. Double-click index.html to open the project in your web browser.
If the project does not work correctly when opened directly, open the folder in Visual Studio Code and run it using the Live Server extension.
Technologies Used
• HTML5 — page structure
• CSS3 — interface styling
• JavaScript — interactive functionality
Project Structure
• index.html — main page of the project
• js/ — JavaScript files
